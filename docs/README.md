# CheckiinproStaySync is a hotel room booking and hotel management platform built with a Node.js/Express backend and a React/Vite frontend. The platform supports customer-facing room browsing and booking, hotel/admin operations, and a super-admin configuration layer for hotel locations and system administration.## Project OverviewThe business domain is a multi-tenant hotel booking workflow:* Users browse hotel rooms, select a room, and create bookings.* Hotels and admins manage rooms, properties, bookings, and hotel-level operations.* Super admins manage location data such as states and districts, and can approve or reject hotels.* Booking workflows include cancellation, check-in/check-out, and temporary-booking/OTP-style flows.## Tech StackBackend:* Node.js* Express 5* MongoDB with Mongoose 9* JWT authentication* Cloudinary/file upload support* Node cron for booking cancellation automation* Nodemailer for OTP or email-related flowsFrontend:* React 19* Vite* React Router DOM* Recharts for dashboard visualizations* Tailwind CSS* Axios for API communication## Repository Layout* Backend: API server, controllers, models, middleware, routes, cron utilities, PDF utilities.* Frontend: React application, protected route components, role-specific dashboard interfaces.## Runtime RolesThe application expects four main roles:* User* Hotel* Admin* SuperadminThe role guard middleware is mapped through the JWT token and the role claims stored on the user or admin entity.```## Important Files\\\* API bootstrap: \\\[Backend/Server.js](Backend/Server.js)\\\* Backend package manifest: \\\[Backend/package.json](Backend/package.json)\\\*
